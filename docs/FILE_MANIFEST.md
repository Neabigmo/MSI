# File manifest

The release contains the locked configuration and environment, modular Python source, two numbered PowerShell runners, cohort-level metadata and public accession-based sample identifiers without direct personal identifiers, authoritative CSV/JSON results, five main figures in PDF/SVG/PNG, supplementary figures, the MSIsensor-RNA adapter and outputs, and the editable LaTeX manuscript with BibTeX, main PDF, and independent Supplement PDF.

The authoritative result files are `results/generated/metrics.csv`, `predictions.csv`, `calibration_curves.csv`, `calibration_case_mix.csv`, `tuning_results.csv`, `paired_bootstrap_contrasts.csv`, `compact_gene_stability.csv`, `compact_rank_frozen_coefficients.csv`, `compact_rank_model.json`, `source_pca_coordinates.csv`, `source_classifier_stratified.csv`, `stable_gene_cohort_directions.csv`, and `stable_gene_pathway_enrichment.csv`. The same directory contains direct-log rank-SVM kernel and score diagnostics, nested fixed-feature control outputs (`fixed_feature_control_metrics.csv`, `fixed_feature_control_predictions.csv`, `fixed_feature_control_panels.csv`, and related summaries), and 500-repetition out-of-bag threshold-stability outputs. Supplementary files include the fixed-probe-mapping sensitivity comparison, raw-array sensitivity, comparator results, and enrichment provenance. `src/figures.py` reconstructs all figures from the supplied derived tables without expression data.

Excluded material includes raw expression matrices, CEL files, restricted clinical data, caches, temporary PDFs, internal review notes, revision gates, local logs, and machine-specific paths.
