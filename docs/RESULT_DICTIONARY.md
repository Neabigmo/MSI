# Result dictionary

`results/generated/metrics.csv` contains cohort-level discrimination, calibration, Brier, and locked-threshold metrics. `results/generated/predictions.csv` contains cohort-local sample identifiers, labels, probabilities, thresholds, and locked predictions. `data/metadata/cohort_manifest.csv` and `results/generated/cohort_manifest.csv` record role, platform, class counts, label source, and expression input.

Supplementary files contain paired cohort-level contrasts, leave-one-cohort-out sensitivity, calibration curves, calibration case-mix summaries, 500-bootstrap feature stability, the nested fixed-discovery-panel representation control, out-of-bag threshold-stability draws and summaries, cross-cohort rank-space directions, direct-log rank-SVM kernel and score diagnostics, g:Profiler enrichment with provenance, PreMSIm comparison, and RMA/fRMA sensitivity results. `fixed_feature_control_metrics.csv` separates `discovery_nested_oof` from `TCGA_to_GEO`; the former is generated without outer-fold panel leakage, while the latter is the final discovery-frozen panel applied to external cohorts. `threshold_stability_draws.csv` records deduplicated original-ID bootstrap fits and out-of-bag threshold estimates; `fit_oob_overlap` is zero in all repetitions. `paired_bootstrap_contrasts.csv` contains the 2,000 paired resamples used for the cohort-level contrasts.
