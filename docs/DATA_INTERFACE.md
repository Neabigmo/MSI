# Data interface

The analysis expects `data/processed/coad_msi_probe_mean/<COHORT>_shared_expression.tsv` and `<COHORT>_labels.csv` for `TCGA_COAD`, `GSE13294`, `GSE13067`, `GSE18088`, `GSE26682`, and `GSE39084`.

Expression files are tab-separated matrices with samples as rows, gene symbols as columns, and `sample_id` as the first-column index. Label files contain `sample_id` and `label`; accepted positive labels are `MSI`, `MSI-H`, and `MSI_H`, and the negative label is `MSS`. All matrices must expose the locked 11,316-gene intersection in a consistent column order. Paths are resolved relative to the repository root; no machine-specific drive letter is required.

For GPL570 series matrices, use one fixed platform annotation for all cohorts, map each probe to its first valid gene symbol, and average all probes assigned to the same gene separately within each sample. Do not select a representative probe from target-cohort means or other target distributional statistics. MSI-L/MSI-low and unknown labels are excluded. Rebuilding validates samples against the released manifest and genes against `data/metadata/shared_gene_set.csv`; it never creates a new GEO-only intersection. These requirements define the processed input interface; upstream preprocessing already embedded in a published series matrix remains outside the sample-wise claim.

The release also contains `data/metadata/coad_msi_labels/sample_manifest.csv` and one label file per cohort. These files provide public accession-based sample IDs without direct personal identifiers, binary labels, label provenance, and an indicator of inclusion in the formal benchmark. They are supplied so that cohort-level counts and sample-level prediction records can be audited without distributing expression data. To rebuild the processed GEO inputs from public series matrices, run `python src/data_ingest.py --output-root data/processed/coad_msi_probe_mean`; the script uses one fixed GPL570 annotation and within-sample probe averaging. The public series matrices may already contain upstream cohort-level normalization, so this command does not claim a raw-CEL single-sample workflow. TCGA TPM and labels must be obtained from GDC/cBioPortal and placed according to the same interface; the release does not yet automate that controlled metadata-joining step.
